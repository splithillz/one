# RP Speller — исправление опечаток в чате GTA V / FiveM

Программа для Windows, которая исправляет опечатки в том, что ты пишешь в игровой чат. Игру и сервер
не трогает: работает как переводчик «RP Chat Overlay» — своё окно поверх игры и нажатия клавиш.

## Как пользоваться

1. Запусти `RPSpeller.exe`. Он сядет значком в трей рядом с часами.
2. В игре нажми **F7**. Программа сама откроет игровой чат клавишей **T** (окружающие видят, что ты
   печатаешь) и покажет поверх игры маленькое окно.
3. Пиши в это окно. Ошибки исправляются сразу после пробела: «здраствуйте» → «здравствуйте».
   Внизу видно, что исправлено. **Backspace сразу после исправления** возвращает слово как было — и это
   слово больше никогда не исправляется.
4. **Enter** — программа проверит всю строку (в том числе последнее слово), вставит текст в игровой чат
   и отправит. **Esc** — закрыть окно и игровой чат без отправки.

Если окно игры не найдено, текст после Enter копируется в буфер обмена — так можно попробовать
программу и без игры: нажми F7 на рабочем столе.

## Что исправляется, а что нет

- Исправляются русские слова от 4 букв с опечатками: пропущенные и лишние буквы, перепутанные соседние,
  слитное написание («вобщем» → «в общем»), слова через дефис. Регистр сохраняется («СИГОДНЯ» → «СЕГОДНЯ»).
- Не трогаются: команды (`/me`, `/do`, `/try` — исправляется только текст после них), латиница, цифры,
  ссылки, имена с большой буквы в середине фразы, чатовый сленг (спс, лол, норм, мб, рп, оос…) и твои
  слова из настроек.

## Требования

- Windows 10 или 11, 64 бита. Ничего устанавливать не нужно — всё внутри одного файла.
- Игра в режиме **«В окне»** или **«Без рамки»**: в полноэкранном режиме окно программы не видно поверх игры.
- Интернет: исправления берутся у Яндекс.Спеллера.
- Если игра запущена от имени администратора — программу тоже запускай от администратора, иначе Windows
  не даст ей переключиться в игру.

При первом запуске Windows может показать «Система Windows защитила ваш компьютер» — программа не подписана
сертификатом. «Подробнее» → «Выполнить в любом случае».

## Настройки

Правый клик по значку в трее → «Настройки»: горячая клавиша, клавиша чата в игре, паузы (если сервер
медленно открывает чат или теряет текст — увеличь паузы), способ ввода (вставка через буфер или печать
по буквам), сразу отправлять или только вставлять, включить/выключить исправления, свои слова.

Файлы лежат в `%APPDATA%\RPSpeller`: `config.json` — настройки, `cache.json` — проверенные слова (знакомые
слова больше не уходят в сеть), `own.json` — слова, которые ты вернул Backspace, `log.txt` — журнал для
разбора проблем (текст сообщений туда не пишется, только исправленные слова).

## Правила сервера

Программа не меняет файлы игры и не лезет в её память: она нажимает клавиши за тебя — так же, как
переводчик «RP Chat Overlay» из раздела «Модификации». Но на некоторых серверах любые сторонние программы
для чата под вопросом — если сомневаешься, спроси администрацию.

## Проверка правописания: [Яндекс.Спеллер](http://api.yandex.ru/speller/)

Исправления — от бесплатного API Яндекс.Спеллера ([условия](https://yandex.ru/legal/speller_api/)):
10 000 обращений и 10 млн символов в сутки на пользователя — для одного игрока это с огромным запасом.
В сеть уходят отдельные слова, а не сообщения целиком.

## Сборка и тесты

```
dotnet test tests/RpSpeller.Core.Tests          # 29 проверок логики, с настоящим Спеллером
dotnet publish src/RpSpeller -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none -o dist
```

Нужен официальный .NET 8 SDK (в пакете .NET из Ubuntu нет поддержки окон Windows). Логика исправления
(`src/RpSpeller.Core`) не зависит от Windows и проверяется тестами на любой системе; оконная часть
(`src/RpSpeller`) — только на Windows.
