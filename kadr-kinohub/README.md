# Кадр — темы для kinohub (в работе)

Расширение для `on.kinohub.vip`: только цветовые темы, без аватара. Тот же дизайн, что у «Кадра» для kinoarc,
но без мелких пояснительных подписей.

## Статус: заготовка, ставить пока рано

Готово:

- интерфейс: «Родная» (сайт как есть), 10 палитр и свой цвет; попап на компьютере и страница на телефоне;
- иконки (тёплый градиент, чтобы не путать с «Кадром» для kinoarc), манифест, доступ только к `on.kinohub.vip`.

Не готово:

- **темы на сайте не применяются** — в расширении ещё нет контент-скрипта. Чтобы его написать, нужны разметка
  и стили on.kinohub.vip, а сайт не отвечает на запросы с сервера разработки (соединение рвётся без ответа).
  Нужен снимок страницы из обычного браузера: сохранённая страница `.mhtml` или «веб-страница полностью»;
- пункт в мобильном меню сайта со шторкой настроек, как на kinoarc, — тоже после снимка.

## Файлы

| Файл | Что делает |
| --- | --- |
| `themes.js` | Палитры и формула (общие с «Кадром» для kinoarc) |
| `popup.html`, `popup.css`, `popup.js` | Интерфейс: попап, страница на телефоне, режим шторки (`#sheet`) |
| `env.js` | До первой отрисовки определяет телефон и режим шторки |
| `icons/` | Иконки; `icon.svg` — исходник |
