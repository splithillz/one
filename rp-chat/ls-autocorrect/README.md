# LS Autocorrect — автоисправление опечаток в игровом чате

Один файл (`ls-autocorrect.js`, без зависимостей) для интерфейса чата (NUI). Работает у игрока, пока он печатает,
как автоисправление в телефонной клавиатуре: игрок пишет «здраствуйте», ставит пробел — и слово само становится
«здравствуйте». Подчёркиваний и подсказок нет, текст просто исправляется.

## Как это выглядит для игрока

- Слово исправляется сразу после пробела или знака препинания; последнее слово — по Enter, перед отправкой.
- Над полем на две секунды появляется «здраствуйте → здравствуйте  ⌫ отменить».
- **Backspace сразу после исправления** возвращает слово как было, и это слово больше никогда не трогается
  (запоминается у игрока навсегда, как личный словарь в телефоне).
- Не трогаются:
  - команды — `/me`, `/do`, `/try` и любые другие; текст после команды исправляется (`/me досал телефон` →
    `/me достал телефон`), сама команда, ID и цифры — нет;
  - латиница, цифры, ссылки, слова короче 4 букв;
  - имена и названия с большой буквы в середине фразы («Джонн», «Палето»);
  - чатовый сленг: спс, пж, лол, кек, норм, мб, хз, крч, имхо, рп, оос и т. п. — список внутри файла,
    свои слова сервера добавляются одной строкой (см. ниже).
- Регистр сохраняется: «Здраствуйте» → «Здравствуйте», «СИГОДНЯ» → «СЕГОДНЯ». Слитное «вобщем» → «в общем».

## Подключение

1. Положить `ls-autocorrect.js` рядом с HTML чата и подключить:

   ```html
   <script src="ls-autocorrect.js"></script>
   ```

2. Привязать к полю ввода чата (после того как оно появилось в DOM):

   ```js
   var ac = LSAutocorrect.attach(document.querySelector('#chat-input'), {
     whitelist: ['лспд', 'сасд', 'вайнвуд', 'палето']
   });
   ```

Работает с обычным `<input>`/`<textarea>`, с Vue (`v-model`) и React (управляемое поле) — исправление попадает
в состояние фреймворка, проверено на Vue 3 и React 18. Если поле создаётся заново при каждом открытии чата —
вызывать `attach` при открытии и `ac.destroy()` при закрытии.

### Настройки

| Опция | По умолчанию | Что делает |
|---|---|---|
| `whitelist` | `[]` | слова сервера, которые не исправлять (без учёта регистра) |
| `minLength` | `4` | слова короче не исправляются |
| `hint` | `true` | подсказка «было → стало ⌫ отменить» над полем (класс `.ls-autocorrect-hint`) |
| `persist` | `true` | помнить проверенные и отменённые слова между сессиями (`localStorage`) |
| `onFix(from, to)` | — | вызывается при каждом исправлении (для логов/статистики) |
| `lang` | `'ru'` | язык проверки (`ru` или `uk`); латиница не проверяется никогда, чтобы не портить ники и английский сленг |

Методы: `ac.addWords([...])` — добавить слова в исключения на лету, `ac.destroy()` — отвязать.

## Откуда исправления и что с лимитами

Проверка идёт через бесплатный API [Яндекс.Спеллера](https://yandex.ru/dev/speller/) прямо из интерфейса игрока
(CORS у API открыт). Отправляются **отдельные слова**, а не сообщения целиком. Без интернета модуль просто
ничего не делает — чат работает как обычно.

Условия API ([yandex.ru/legal/speller_api](https://yandex.ru/legal/speller_api/)):

- можно бесплатно, в том числе в коммерческих проектах;
- лимиты — 10 000 обращений и 10 млн символов в сутки (п. 3.2); в условиях они записаны на «пользователя»
  сервиса, то есть, по букве, на проект целиком;
- **обязательна подпись** «Проверка правописания: Яндекс.Спеллер» со ссылкой на http://api.yandex.ru/speller/ —
  в описании, справке или на сайте проекта, шрифтом не меньше основного (п. 3.8). Например, в теме о чате
  на форуме или в разделе помощи.

Чтобы тратить как можно меньше обращений:

- проверяются только слова, которые закончены (после пробела/знака) или на которых игрок остановился;
- несколько слов уходят одним обращением;
- каждое проверенное слово — и верное, и с ошибкой — запоминается у игрока (до 20 000 слов), так что его
  привычный словарь быстро перестаёт уходить в сеть: после перезагрузки знакомые слова не вызывают ни одного
  запроса.

Если онлайна много и лимит станет тесным, варианты — договориться с Яндексом или перейти на офлайн-словарь
(без сети и лимитов, но исправления слабее). Модуль устроен так, что источник исправлений меняется в одном месте
(`flush`).

## Что важно проверить на сервере

- **Интерфейс чата должен иметь доступ в интернет.** Если у страницы чата есть Content-Security-Policy —
  добавить `https://speller.yandex.net` в `connect-src`.
- Модуль слушает Enter на уровне окна в фазе перехвата и исправляет последнее слово до того, как сработает
  отправка чата. Если чат отправляет сообщение не по Enter, а по своей кнопке — последнее слово исправится,
  только если игрок поставил после него пробел или знак.

## Проверено

В Chromium (на нём же основан интерфейс FiveM — CEF), `tests/`:

- `autocorrect.test.js` на `demo.html` — 15 проверок: исправление после пробела и по Enter, отмена Backspace
  и память об отменённом после перезагрузки, команды, имена, латиница, цифры, сленг, капс, слова через дефис,
  слитное написание, быстрый набор нескольких слов с ошибками, повторный заход без запросов;
- `vue.html` и `react.html` — исправление видно в состоянии Vue 3 и React 18, по Enter уходит исправленный текст.

В самой игре (FiveM) не проверялось — нет клиента. `demo.html` можно открыть в обычном браузере и попробовать.
