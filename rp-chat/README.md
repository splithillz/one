# RP-чат (GTA V / FiveM)

Два способа избавиться от опечаток в игровом чате.

| Папка | Что это | Для кого | Скачать |
|---|---|---|---|
| [rp-speller](rp-speller/) | RP Speller — программа для Windows: окно ввода поверх игры, опечатки исправляются, текст уходит в чат | для игрока | [RPSpeller-0.3.0.zip](https://github.com/splithillz/one/raw/main/releases/RPSpeller-0.3.0.zip) |
| [ls-autocorrect](ls-autocorrect/) | LS Autocorrect — один JS-файл для интерфейса чата: исправляет опечатки, пока игрок печатает | для сервера | [ls-autocorrect.js](https://github.com/splithillz/one/raw/main/rp-chat/ls-autocorrect/ls-autocorrect.js) |

Оба берут исправления у Яндекс.Спеллера и не трогают команды, ники и чатовый сленг.
