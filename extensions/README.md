Каждая папка расширения — это и есть расширение: в ней лежит `manifest.json`, её можно загрузить в браузер как есть.

Поставить: распакуй архив, открой `chrome://extensions`, включи «Режим разработчика» и нажми «Загрузить распакованное» — выбери папку с `manifest.json`.
