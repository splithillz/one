# Полный прогон Kadr по живому форуму

Набор тестов, которым проверяется каждая версия `kadr-lsforum` перед выпуском — прямо на `forum.ls-project.com`,
гостем и в аккаунте, в Chromium с эмуляцией телефона, планшета и компьютера.

## Запуск

```
cd kadr-lsforum-tests
KADR_CRED=/путь/вне/репозитория/cred.json ./run-all.sh      # гость + аккаунт
./run-all.sh                                                # только гость
```

`cred.json` — `{"user": "почта или ник", "pass": "пароль"}`. Файл должен лежать вне репозитория; путь к нему
передаётся только переменной окружения. Нужен установленный Playwright с Chromium. Прогон идёт несколько часов;
логи и снимки — в `out/`, в конце печатается сводка.

## Аккаунт только читается

- Браузер теста блокирует любую запись на форум: все POST и все ссылки-действия (удалить, скрыть, закрепить,
  переместить, реакция, отписка, «прочитано», выйти из беседы, очистить папку, отключить ЛС, выход и подобные).
  Пропускаются только вход и выход в начале и в конце. Заблокированное печатается в логе.
- Запросы уведомлений тоже блокируются — прогон не помечает их прочитанными.
- Чужие профили в аккаунте не открываются (визит видно в «Посетителях профиля»), беседа открывается только
  прочитанная.
- Редактирование своего поста — открыть и нажать «Отмена»; ответ в редакторе не набирается и не отправляется.

## Что проверяется

- `live-interact.js` — взаимодействия на каждой странице: окна (открыть, вид, закрыть крестиком, тапом по фону,
  Escape), редактор ответа и его выпадашки, смайлы, «Цитата» и мультицитата, редактирование своего поста с отменой,
  спойлеры, вкладки, боковое меню «≡», карточки пользователей и подсказки, пагинация; зависания дольше 0,5 с,
  ошибки скриптов, неожиданные переходы. Каждая проверка сравнивается с тем же действием без расширения:
  то, что так же ведёт себя у самого форума, считается отдельно и в ошибки не идёт.
- `menus.js` — каждое выпадающее меню: непрозрачное, не обрезано, не перекрыто, на экране; закрывается тапом мимо
  и повторным тапом по своей кнопке, открывается снова, не остаётся висеть.
- `audit.js` — 36 состояний на страницу: контраст текста, переполнение по ширине (360–1920 px), цвета темы,
  ошибки скриптов; тёмная и белая схема.
- `pp.js` — пиксели: текст в кнопках и чипах по центру, кнопки в ряд одной высоты, значки по центру по снимку.
- `day-night.js` — «День и ночь» и «Текст постов»: схема вживую вслед за системой (эмуляция светлой и тёмной),
  ни одного кадра в чужой схеме при загрузке, пары Monet, «всё выключено» ничего не трогает, переключатель ◐
  форума, размер текста постов, крупный текст без прокрутки вбок, кнопки в попапе.
- `post-fit.js` — содержимое постов: на телефоне (412 и 360 px) и компьютере ничто в посте не выходит за карточку,
  в том числе добавленные широкие таблицы, блоки, iframe и картинки (картинки без искажения пропорций); подгонка
  не меняет ни одного элемента, если в посте ничего не вылезает; поворот телефона и появление адресной строки;
  HTML постов, из которого форум собирает цитату, совпадает с форумом без расширения; ошибок скриптов нет.
- `monet-check.js`, `flexpseudo.js`, `gutter.js`, `lsp-collapse2.js`, `lsp-frames.js`, `ls-new.js`, `ls-sheet.js`,
  `font-flash.js`, `ls-fouc.js`, `ic-fouc.js`, `scheme-force.js`, `off-sticky.js` — схема Monet, лишние флекс-элементы,
  края карточек, виджет онлайна, шторка настроек, мигания при загрузке, принудительная схема, выключенное
  расширение.

## Firefox

`firefox/run-firefox.sh` прогоняет те же страницы в Firefox и в Chromium и сравнивает: тему, схему, цвета, шрифт,
иконки, стекло, кнопки, ширину блоков и цвет каждого цветного текста. Потом во Firefox проверяет меню, боковое
меню, шторку «Тема» и подсказки.

```
curl -O https://archive.mozilla.org/pub/firefox/releases/160.0/linux-x86_64/en-US/firefox-160.0.tar.xz
tar -xJf firefox-160.0.tar.xz                           # сверить с SHA256SUMS из той же папки
cd kadr-lsforum-tests/firefox && PUPPETEER_SKIP_DOWNLOAD=1 npm i puppeteer@24
FF=/путь/к/firefox/firefox ./run-firefox.sh
```

Firefox управляется через WebDriver BiDi, расширение ставится временно. Настройки тестовая копия расширения
берёт из адреса страницы (`#kadrtest=…`, файл `test-set.js`); в выпуск этот файл не входит. Телефон — Firefox для
компьютера с мобильным User-Agent, касаниями и накладными полосами прокрутки; это близко к Firefox для Android,
но не он.
